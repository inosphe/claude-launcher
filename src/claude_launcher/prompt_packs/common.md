## 이 워크스페이스의 공통 작업 규칙

이 묶음은 이 워크스페이스의 세션이 공통으로 따르는 지침이다. 워크스페이스에
설치된 사본(`.claunch/prompts/common.md`)을 그 저장소의 규칙에 맞게 고쳐 쓴다.
고친 사본은 패키지 갱신으로 덮이지 않는다.

### 작업 방식

- 작업을 시작하기 전에 저장소의 에이전트 규칙 파일(`AGENTS.md`, `CLAUDE.md`)을 읽는다.
  이 묶음과 그 파일이 다르면 그 파일을 따른다.
- 지시받은 범위 밖의 변경은 하지 않는다. 필요해 보이면 먼저 묻거나 별도 일감으로 남긴다.
- 되돌리기 어려운 작업(삭제, 강제 push, 공유 브랜치 머지, 외부 서비스 게시)은 실행하기
  전에 확인을 받는다.

### 임시 파일

- `/tmp/<고정 이름>`을 쓰지 않는다. 이 머신의 모든 세션이 같은 디렉터리를 쓰므로 다른
  세션의 파일과 경고 없이 겹친다.
- 중간 파일은 `$CLAUNCH_SCRATCH`(세션마다 데몬이 만든 디렉터리)에 쓴다.
- 테스트 산출물 중 pytest basetemp 밖의 것(브라우저 프로필, playwright 리포트,
  node 테스트 출력 등)은 `$CLAUNCH_TEST_DIR`(테스트 산출물 루트의 세션별 하위
  디렉터리, 세션마다 데몬이 만들고 종료 시 회수)에 쓴다. 루트 자체는
  `daemon.test_output_dir` 설정으로 명시한다 — 그 밖의 임의 경로에 만들지 않는다.
- 작업 트리 안에 임시 파일을 남기지 않는다.

### 백그라운드 작업 기다리기

- 하네스의 백그라운드 실행(Claude Code Bash의 `run_in_background`)은 끝나면 완료
  알림이 온다. 따로 기다리는 루프를 만들지 않는다.
- 셸에서 기다려야 하면 띄울 때 `$!`로 pid를 받아 `kill -0 <pid>`로 확인한다.
- `pgrep -f "<명령 문자열>"`로 기다리지 않는다. 기다리는 셸의 명령줄에도 같은
  문자열이 있어 자기 자신에 매치되고, 작업이 끝난 뒤에도 루프가 끝나지 않는다.

### pytest가 아닌 테스트

- pytest가 아닌 테스트·빌드 명령을 쓰는 저장소용 지침은 프롬프트 팩
  `non-pytest-project`에 있다. 필요한 세션이나 워크스페이스에만 추가한다.

### 데몬

- `claunch daemon restart`, `claunch daemon stop`은 실행하지 않는다. 데몬에 붙은 모든
  세션이 함께 종료된다. 재기동이 필요하면 사용자에게 요청한다.

### 보고

- 권한 분류기(`automode`)에 의해 동작이 차단되면 MCP nudge 도구로 사용자에게
  보고한다. 차단된 동작, 분류기가 반환한 사유, 사용자에게 필요한 조치를 적는다.
  현재 `flow_nudge`는 cflow 런이 사람의 응답을 기다릴 때만 사용할 수 있다.
  그 조건이 없거나 cflow 런이 없으면 `mcp-threads` 지침에 따라 같은 주제의
  `thread_reply` 또는 새 주제의 `thread_open`으로 알린다. nudge 호출을 위해
  워크플로에 불필요한 대기 상태를 만들지 않는다.
- 다른 세션의 응답을 기다리며 같은 대기 단계를 반복할 때(예: 착지 요청 뒤
  await-landing과 landing-nudge의 순환)는 대기 한도에 닿기 전에 사용자에게 알린다.
  터미널 출력과 이슈 코멘트는 사용자에게 알림이 가지 않는다. 알림 경로는
  `thread_reply`(같은 주제의 스레드가 있을 때)와 `thread_open`(없을 때)이다.
  알릴 내용은 기다리는 대상, 대기 시간, 지금까지 보낸 재촉 횟수, 사용자가 고를 수
  있는 선택지다. 런이 사람의 승인을 기다리는 상태가 되면(`loop_limit` 등) 그때
  `flow_nudge`로 대시보드 카드도 올린다. 바뀐 값이 없으면 같은 알림을 반복하지 않는다.
  임계값은 대기 단계를 정의한 워크플로가 정한다.
- 결과는 확인한 사실대로 적는다. 테스트가 실패했으면 실패 출력을 함께 적고, 건너뛴
  단계가 있으면 건너뛰었다고 적는다.
- 원인을 확인하지 못한 문제는 「원인 미상」으로 적는다.
