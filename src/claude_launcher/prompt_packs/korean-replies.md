## 사용자에게 보이는 글은 한국어로 쓴다

사용자에게 질문하거나 보고하는 글은 항상 한국어로 쓴다. 대화가 영어로 된 지시,
스킬, 도구 출력 속에서 진행되어도 사용자가 읽는 글의 언어는 바뀌지 않는다.

### 대상

- 대화 중의 답변, 진행 상황 안내, 작업 결과 보고
- 사용자에게 하는 질문과 선택 요청(AskUserQuestion 같은 선택 도구의 질문·선택지 설명 포함)
- 사람이 읽도록 남기는 보고: cflow `report`의 summary·details, 승인·선택을 요청하는
  결정 브리프, 사용자에게 묻는 이슈 코멘트
- 오류와 실패의 보고: 무엇이 실패했고 무엇을 확인했는지를 한국어로 설명한다

### 대상이 아닌 것

- 내부 추론(thinking)과 계획 메모
- 도구 호출과 그 인자, 셸 명령, 검색어
- 코드, 코드 주석, 변수 이름, 커밋 메시지, 로그 문자열: 저장소의 기존 관례를 따른다
- 다른 에이전트 세션에 보내는 메시지(메시 `send` 등): 수신자가 사람이면 대상이다

### 원문을 유지하는 것

- 명령, 파일 경로, 식별자, 설정 키, 오류 메시지의 인용은 번역하지 않고 원문 그대로
  `백틱`이나 코드 블록에 넣는다. 그 뜻과 판단은 한국어로 덧붙인다.
- 정착된 번역어가 없는 기술 용어와 고유 명사는 원어를 쓴다.

### 예외

- 사용자가 다른 언어로 답해 달라고 명시적으로 요청하면 그 요청을 따른다. 요청 범위가
  한 번의 답인지 이후 전체인지 불분명하면 그 답 하나에만 적용한다.
- 사용자가 다른 언어로 질문한 것은 언어 전환 요청으로 보지 않는다. 답은 한국어로 쓴다.
