VM 등록

이 호스트의 tart에 있는 VM을 골라 등록합니다. 등록해도 VM은 시작·종료되지 않고, 실행 중이면 상태만 채택합니다.

프리셋

정지된 VM을 복사해 두었다가 새 VM을 만드는 틀입니다. 복제본은 원본의 계정·admin 비밀번호·키와 게스트 DNS 설정을 그대로 가집니다. 새 VM은 사설 대역을 막는 softnet으로 시작하며, 이 네트워크에서는 게이트웨이 DNS를 쓸 수 없으므로 저장하기 전에 원본 게스트의 DNS를 공용 서버로 설정하십시오(networksetup -setdnsservers Ethernet 1.1.1.1 8.8.8.8).

    대기 중인 요청

    세션이 vm_request로 요청한 권한과 공유 폴더입니다. 승인하면 권한 부여와 공유 폴더 추가가 한 번에 적용되고, 거절하면 요청만 사라집니다. 세션이 끝나면 대기 중인 요청은 사라지지만 이미 승인된 공유 폴더는 남습니다.

    세션의 VM

    이 세션에 권한이 부여된 VM입니다. '연결 해제'는 이 세션의 권한만 회수하며 VM을 정지하거나 삭제하지 않습니다. 이 화면의 동작은 모두 사용자 전용이며 세션은 호출할 수 없습니다.

      파일

      files 권한이 있는 세션은 vm_put·vm_get·vm_ls·vm_rm으로 아래 두 폴더 사이에서만 파일을 복사하거나 지웁니다. 경로는 각 폴더 기준 상대 경로이며 절대 경로, .., 심볼릭 링크는 거절됩니다. 받은 파일은 실행하지 않습니다. 호스트 폴더에 쓰는 파일은 일반 파일과 폴더뿐이고, 소유자 권한만 남기며 setuid는 제거합니다. 호스트에서 열거나 실행하기 전에 내용을 직접 확인하십시오.

      호스트 폴더

      /Users/<계정>/<폴더>, /private/tmp/<폴더>, /tmp/<폴더> 아래만 지정할 수 있습니다(숨김 폴더·Library·공백 제외). 변경은 사용자만 할 수 있고 감사 기록에 남습니다.

      시각세션작업경로크기결과

      최근 전송은 데몬이 시작된 뒤의 기록이며 경로와 바이트 수만 남기고 내용은 남기지 않습니다.

      공유 폴더 (호스트 → 게스트)

      호스트 폴더를 게스트의 /Volumes/My Shared Files/<이름>에 마운트합니다(tart run --dir). 세션은 호스트 경로에서 편집하고, 빌드와 git은 게스트의 로컬 사본에서 실행해야 합니다. 공유 폴더에서는 파일이 많을 때 약 10배 느리고 방금 쓴 파일에 대해 swiftc 오류가 납니다. 기본은 읽기 전용(ro)이며 쓰기(rw)는 명시적으로 고른 경우만 허용합니다. 변경은 VM을 다음에 시작할 때 적용됩니다.

      이름호스트 경로게스트 경로모드출처상태

      포트 노출 (softnet)

      외부 포트는 호스트와 같은 LAN의 모든 기기에서 접속할 수 있습니다. 허용 주소는 softnet 필터가 게스트와의 통신을 통과시키는 주소입니다. 게스트가 그 주소에 접속할 수 있게 되며, 외부 포트로 접속해 오는 기기의 주소도 여기에 있어야 합니다. 호스트 방화벽은 바꾸지 않습니다. 변경은 VM을 다음에 시작할 때 적용됩니다. 광범위한 허용(0.0.0.0/0, /8보다 넓은 값, 사설 대역 전체, 호스트 자신의 주소를 포함하는 값)은 격리가 사라지므로 거절됩니다.

      등록 해제

      데몬이 이 VM을 잊습니다(권한 부여, 공유 폴더, 대기 요청 기록이 사라짐). tart VM과 디스크 이미지는 호스트에 그대로 남고, 다시 등록할 수 있습니다. 정지·일시 중단·오류 상태의 VM만 해제할 수 있습니다.

      위험 영역: 물리적 삭제

      tart delete로 이 VM의 디스크 이미지까지 영구 삭제합니다. 되돌릴 수 없습니다. 정지된 VM만, 잠금이 풀려 있고 세션이 권한을 가지고 있지 않을 때만 삭제할 수 있습니다. 등록 기록, 권한, 공유 폴더 카탈로그의 이 VM 항목, 대기 요청도 함께 정리됩니다. 삭제는 호스트 audit 로그에 남습니다. (프리셋 삭제는 프리셋 목록에서 하며 tart의 preset-<이름> 복사본을 지웁니다.)

          전체 복제 계보(모든 VM·프리셋)

          프리셋과 그것으로 만든 VM의 복제 관계입니다(읽기 전용). 데몬이 프리셋으로 VM을 만들 때 어느 프리셋에서 복제했는지 기록하며, 그 기록이 없는 VM(직접 등록했거나 이 기능 이전에 만든 VM)은 복제 출처를 추측하지 않고 "출처 기록 없음"으로 표시합니다. tart 이미지(OCI) 이름은 tart가 알려 주지 않아 표시하지 않습니다. 프리셋을 지우면 그 후손 VM은 "삭제된 프리셋에서 복제"로 표시됩니다.

          전체 트리 펼치기(선택한 VM은 강조됩니다)

            등록된 VM이나 프리셋이 없습니다.

            VM 전용 모드

            켠 세션은 호스트에서 빌드(make, xcodebuild, npm run, pytest …), 패키지 설치(npm/pip/brew install …), 프로그램 실행(python, node, ./스크립트, open …)을 실행할 수 없고, 거절 메시지가 vm_exec로 VM에서 실행하라고 안내합니다. git, claunch, 읽기 명령은 그대로 쓸 수 있습니다. 다음 Bash 호출부터 적용됩니다. 접두 규칙이므로 스크립트 파일, alias, 변수 치환으로 우회할 수 있고, 세션이 자기 세션 폴더의 vm-only.json을 지워 스스로 끌 수도 있습니다. 유도 장치이며 보안 경계가 아닙니다. Claude Code 세션 중 이 기능이 들어간 뒤 시작한(또는 다시 시작한) 세션에서만 켤 수 있습니다.

            공유 폴더

            카탈로그는 모든 VM 또는 지정한 VM에 공유할 호스트 폴더 목록입니다. VM이 시작될 때 VM 자체의 공유 폴더와 합쳐 마운트하며(한 VM에 최대 4개, 이름이 같으면 VM 자체 항목이 우선), 변경은 실행 중인 VM에서는 다시 시작해야 적용됩니다. 기본은 읽기 전용(ro)입니다. 공유 폴더는 게스트에 열려 있어, ro여도 폴더 안의 비밀(.env 등)을 게스트가 읽을 수 있고, rw이면 게스트가 .git/hooks나 스크립트를 심어 호스트 세션이 실행하게 할 수 있습니다.

            공유 허용 루트

            공유할 수 있는 폴더는 여기에 등록한 루트 아래로 제한됩니다. 비어 있으면 공유가 꺼져 있습니다. 홈 폴더 자체, ~/.ssh, ~/.gnupg, ~/.aws, ~/Library, ~/.claude*, 데몬 상태 폴더는 등록할 수 없습니다. 변경은 다음 공유/시작부터 적용되며 데몬을 다시 시작할 필요가 없습니다. 세션은 이 목록을 바꿀 수 없습니다.
