claunch vm
VM 등록

이 호스트의 tart에 있는 VM을 골라 등록합니다. 등록해도 VM은 시작·종료되지 않고, 실행 중이면 상태만 채택합니다.

프리셋

정지된 VM을 복사해 두었다가 새 VM을 만드는 틀입니다. 복제본은 원본의 계정·admin 비밀번호·키와 게스트 DNS 설정을 그대로 가집니다. 새 VM은 사설 대역을 막는 softnet으로 시작하며, 이 네트워크에서는 게이트웨이 DNS를 쓸 수 없으므로 저장하기 전에 원본 게스트의 DNS를 공용 서버로 설정하십시오(networksetup -setdnsservers Ethernet 1.1.1.1 8.8.8.8).

    세션 권한

    view 화면 보기, control 화면 조작(view 포함), exec 게스트 셸 실행과 설치·설정 변경. control만으로도 Terminal을 띄워 명령을 입력할 수 있으므로 control은 셸 실행에 준하는 신뢰입니다.

    한계: 데몬은 토큰 하나로 사용자와 세션을 구분하지 못합니다. 같은 OS 사용자로 토큰을 읽을 수 있는 프로세스(관리 세션의 셸 포함)는 이 페이지의 동작을 사용자 이름으로 호출할 수 있습니다. 그래서 이 페이지의 변경은 감사 기록에 선언된 주체(actor)와 함께 남습니다.

    포트 노출 (softnet)

    외부 포트는 호스트와 같은 LAN의 모든 기기에서 접속할 수 있습니다. 허용 주소는 softnet 필터가 게스트와의 통신을 통과시키는 주소입니다. 게스트가 그 주소에 접속할 수 있게 되며, 외부 포트로 접속해 오는 기기의 주소도 여기에 있어야 합니다. 호스트 방화벽은 바꾸지 않습니다. 변경은 VM을 다음에 시작할 때 적용됩니다. 광범위한 허용(0.0.0.0/0, /8보다 넓은 값, 사설 대역 전체, 호스트 자신의 주소를 포함하는 값)은 격리가 사라지므로 거절됩니다.
